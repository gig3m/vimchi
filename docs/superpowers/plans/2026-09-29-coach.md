# Coach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After a rounds lesson or a challenge run (and live, behind a setting), show the learner concrete "you typed X, a better Vim user types Y" lines derived from their own keystrokes, gated to keys the curriculum has taught.

**Architecture:** The Vim engine reports what each completed command *was* (`lastCommand`). `Session` logs every fed key with that classification. A pure `src/coach/` module segments the log into motion runs and edits, searches for shorter motions (pure step functions over the buffer, verified by replaying on a scratch Vim rebuilt from the round's setup), matches edit windows against a rule library, filters by a vocabulary gate and pedagogical heuristics, and emits a report. UI renders the report under the results rings and, optionally, one live line under the editor.

**Tech Stack:** TypeScript, React 19, vitest 5, the in-repo Vim engine (`src/vim`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-29-coach-design.md`

## Global Constraints

- Coach runs only for `rounds` lessons and `generated` challenges; never for `target`/`word`/`fix`/`replace`/`quiz`, never for lessons in the Macros section (`macros`), never for Plugins-band sections.
- A suggestion shows only when `saves >= 2` or `learnerKeys >= 1.5 * suggestedKeys`.
- Counts on motions are taught from lesson `words` (`COUNTS_TAUGHT_FROM = 'words'`); counts only on `h j k l` (2–9); on `w b e W B E` capped at 3; never on `f t F T`.
- `G`/`gg` only when the target is the last/first line; `{`/`}` only when the target line is blank. `;`/`,` only after an `f/t/F/T` inside the same suggestion.
- Never replace a key the current lesson's `chips` contain when the learner used it in that segment.
- Every suggestion is verified by replay on a scratch Vim (text, cursor, mode, and any state a later command in the unit reads) before it is shown; a failed replay drops it silently.
- Scores and `Run` are unchanged; nothing new goes to the server. The live nudge setting is `localStorage` key `vimchi.coach.v1`, default off.
- `npm test` and `npx tsc -b` green at the end of every task.

## Review Focus

1. **The learner types a key that errors (e.g. `fz` with no `z` on the line) then the right key.** Expected: the typo is not critiqued and does not pollute the motion run's start. Pinned in Task 3 (`a typo key is removed from a run`).
2. **The learner uses `p` after the coach would have replaced `xxxx` with `de`.** Expected: the `de` suggestion is dropped because the unnamed register would differ and a later `p` reads it. Pinned in Task 4 (`state a later command reads must match`).
3. **A round where the cursor carried over from the previous round.** Expected: no reference line claiming the learner "used N more than the reference" when the reference starts elsewhere; par (which includes `carryExtra`) is the comparison. Pinned in Task 8 (`reference lines use par, not raw solution length`).
4. **Live nudge on when a round completes on the last key of a motion run.** Expected: that run is still critiqued (segment closes on goal met) and the nudge is cleared when the next round loads. Pinned in Task 10 (Playwright step checks the nudge text appears and then clears on advance).
5. **A chip that is prose, not a key (`macros`, `init.lua`, `vim.opt`).** Expected: the tokenizer yields nothing rather than a fake key, and no suggestion is gated by accident. Pinned in Task 5 (`prose chips tokenize to nothing`).

```ts
// src/coach/segment.ts
// Cuts a session key log into motion runs, edits and breaks. Positive classification: a
// motion run is built only from commands the engine reported as motions.
import type { LogEntry } from '../lessons/runtime';
import type { CommandKind } from '../vim/editor';
import type { Key } from '../vim/keys';
import type { Pos } from '../vim/types';

export type Segment =
  | { kind: 'motion'; unit: number; keys: Key[]; from: Pos; to: Pos; logStart: number; logEnd: number }
  | { kind: 'edit'; unit: number; keys: Key[]; from: Pos; logStart: number; logEnd: number; command: CommandKind }
  | { kind: 'break'; unit: number; keys: Key[]; logStart: number; logEnd: number; reason: 'undo' | 'error' | 'other' | 'modal' | 'cmdline' | 'boundary' | 'recording' };

const EDIT_KINDS = new Set<CommandKind>(['operator', 'action', 'insert', 'visual']);

export function segment(log: LogEntry[]): Segment[] {
  const out: Segment[] = [];
  let i = 0;
  const flushMotion = (m: Segment | null) => { if (m) out.push(m); return null; };
  let motion: (Segment & { kind: 'motion' }) | null = null;

  while (i < log.length) {
    const start = i;
    // Collect keys until a command completes (pending keys attach to their command).
    while (i < log.length && log[i].command === null && !(i > start && log[i].boundary)) {
      // Keys typed in insert/cmdline/visual belong to the command in progress; stop at a boundary.
      i++;
      if (i < log.length && log[i].boundary) break;
    }
    if (i >= log.length) { // trailing keys that completed nothing
      motion = flushMotion(motion);
      out.push({ kind: 'break', unit: log[start].unit, keys: log.slice(start).map(e => e.key), logStart: start, logEnd: log.length - 1, reason: 'other' });
      break;
    }
    if (log[i].boundary && i > start) { // boundary inside: flush what we had as a break, restart there
      motion = flushMotion(motion);
      out.push({ kind: 'break', unit: log[start].unit, keys: log.slice(start, i).map(e => e.key), logStart: start, logEnd: i - 1, reason: 'boundary' });
      continue;
    }
    const e = log[i];
    const cmd = e.command!;
    const keys = log.slice(start, i + 1).map(x => x.key);
    const unit = log[start].unit;
    const from = log[start].before.pos;
    const sameRun = motion && motion.unit === unit && !log[start].boundary;
    i++;

    if (cmd.error) {
      motion = flushMotion(motion);
      out.push({ kind: 'break', unit, keys, logStart: start, logEnd: i - 1, reason: 'error' });
      continue;
    }
    if (cmd.kind === 'motion' && e.after.mode === 'normal' && e.after.pending === 0) {
      if (sameRun) { motion!.keys.push(...keys); motion!.to = e.after.pos; motion!.logEnd = i - 1; }
      else { motion = flushMotion(motion); motion = { kind: 'motion', unit, keys, from, to: e.after.pos, logStart: start, logEnd: i - 1 }; }
      continue;
    }
    motion = flushMotion(motion);
    if (cmd.kind === 'undo') {
      // Discard the most recent edit (it was undone) and the undo itself.
      const last = out.length ? out[out.length - 1] : null;
      if (last && last.kind === 'edit') out[out.length - 1] = { kind: 'break', unit: last.unit, keys: last.keys, logStart: last.logStart, logEnd: last.logEnd, reason: 'undo' };
      out.push({ kind: 'break', unit, keys, logStart: start, logEnd: i - 1, reason: 'undo' });
      continue;
    }
    if (EDIT_KINDS.has(cmd.kind)) {
      // An edit extends until the buffer is back in normal mode with nothing pending
      // (insert text, visual motions, cmdline typed for an operator).
      let end = i - 1;
      while (!(log[end].after.mode === 'normal' && log[end].after.pending === 0) && end + 1 < log.length && !log[end + 1].boundary) end++;
      i = end + 1;
      out.push({ kind: 'edit', unit, keys: log.slice(start, end + 1).map(x => x.key), from, logStart: start, logEnd: end, command: log[end].command?.kind ?? cmd.kind });
      continue;
    }
    const reason = cmd.kind === 'modal' ? 'modal' : cmd.kind === 'cmdline' ? 'cmdline' : 'other';
    let end = i - 1;
    if (cmd.kind === 'cmdline') while (log[end].after.mode !== 'normal' && end + 1 < log.length && !log[end + 1].boundary) end++;
    i = end + 1;
    out.push({ kind: 'break', unit, keys: log.slice(start, end + 1).map(x => x.key), logStart: start, logEnd: end, reason });
  }
  motion = flushMotion(motion);
  return out;
}
```

```ts
// src/coach/replay.ts
// Rebuild the engine state at any point of a logged unit, and compare outcomes.
import { type LogEntry, createVim } from '../lessons/runtime';
import type { Setup } from '../lessons/types';
import type { Vim } from '../vim/editor';

export type SessionLike = { log(): LogEntry[]; setupFor(unit: number): Setup; unitStart(unit: number): number };

export function stateBefore(s: SessionLike, i: number): Vim {
  const log = s.log();
  const unit = log[i]?.unit ?? log[log.length - 1].unit;
  const vim = createVim(s.setupFor(unit));
  for (let k = s.unitStart(unit); k < i; k++) vim.feed(log[k].key);
  return vim;
}

export type StateNeeds = { register: boolean; lastFind: boolean; search: boolean; lastChange: boolean };

const READS_REGISTER = /^(?:"[^"]?)?[0-9]*[pP]$/;          // p, P, "ap, 3p
const READS_FIND = /^[0-9]*[;,]$/;
const READS_SEARCH = /^[0-9]*(?:n|N|cgn|cgN|dgn)$|^:s\//; // n N cgn, :s//
const READS_CHANGE = /^[0-9]*\.$/;
const WRITES_REGISTER = /^(?:"[^"]?)?[0-9]*(?:[xXdDcCsSyY]|dd|yy|cc)/;
const WRITES_FIND = /^[0-9]*[ftFT]./;
const WRITES_SEARCH = /^[/?*#]/;

/** Which state a suggestion must preserve: read by a later command in the unit before any command overwrites it. */
export function stateNeeds(log: LogEntry[], afterIndex: number, unit: number): StateNeeds {
  const needs: StateNeeds = { register: false, lastFind: false, search: false, lastChange: false };
  const open = { register: true, lastFind: true, search: true, lastChange: true };
  for (let i = afterIndex + 1; i < log.length; i++) {
    const e = log[i];
    if (e.unit !== unit || e.boundary) break;
    if (!e.command || e.command.error) continue;
    const k = e.command.keys.join('');
    if (open.register && READS_REGISTER.test(k)) needs.register = true;
    if (open.lastFind && READS_FIND.test(k)) needs.lastFind = true;
    if (open.search && READS_SEARCH.test(k)) needs.search = true;
    if (open.lastChange && READS_CHANGE.test(k)) needs.lastChange = true;
    if (WRITES_REGISTER.test(k)) open.register = false;
    if (WRITES_FIND.test(k)) open.lastFind = false;
    if (WRITES_SEARCH.test(k)) open.search = false;
    if (e.command.kind === 'operator' || e.command.kind === 'action' || e.command.kind === 'insert') open.lastChange = false;
  }
  return needs;
}

export function sameOutcome(a: Vim, b: Vim, needs: StateNeeds): boolean {
  if (a.buf.text() !== b.buf.text()) return false;
  if (a.cursor.line !== b.cursor.line || a.cursor.col !== b.cursor.col) return false;
  if (a.mode !== b.mode) return false;
  if (needs.register && a.getRegister('"').text !== b.getRegister('"').text) return false;
  if (needs.lastFind && JSON.stringify(a.lastFind) !== JSON.stringify(b.lastFind)) return false;
  if (needs.search && a.search.pattern !== b.search.pattern) return false;
  if (needs.lastChange && JSON.stringify(a.lastChange?.body ?? null) !== JSON.stringify(b.lastChange?.body ?? null)) return false;
  return true;
}
```

`a.search.pattern` and `lastChange.body` are the engine's real field names (editor.ts:166 and :137–143).

```ts
// src/coach/vocab.ts
// What the curriculum has taught by a given lesson, and which lessons the coach runs on.
import { LESSONS, ORDER, SECTIONS, sectionOf } from '../lessons';

/** Counts on motions are explained in prose here ("3w jumps three words ahead"). */
export const COUNTS_TAUGHT_FROM = 'words';

const NAMED: Record<string, string> = { esc: '<Esc>', cr: '<CR>', enter: '<CR>', '<leader>': '<Space>', '␣': '<Space>', tab: '<Tab>' };
const PROSE = /^[a-z]+(\.[a-z]+)+$|^[a-z]{4,}$/i; // init.lua, vim.opt, macros, norm(al)

/** Split a chip into engine tokens: operators, motions, text objects, prefixes, specials. */
export function tokenize(chip: string): string[] {
  const parts = chip.trim().split(/\s+/);
  const out: string[] = [];
  for (let p of parts) {
    if (!p) continue;
    const low = p.toLowerCase();
    if (NAMED[low]) { out.push(NAMED[low]); continue; }
    if (/^C-.$/i.test(p)) { out.push(`<C-${p[2].toLowerCase()}>`); continue; }
    if (PROSE.test(p) && !/^[gz][a-z]$/.test(p)) continue;
    if (p.startsWith(':')) { out.push(':'); continue; }
    if (/^[/?]/.test(p)) { out.push(p[0]); continue; }
    if (/^\\/.test(p)) continue;                         // regex atoms, not keys
    p = p.replace(/^[0-9]+/, '');                        // leading count
    if (p.startsWith('␣')) { out.push('<Space>'); p = p.slice(1); }
    while (p.length) {
      let m: RegExpMatchArray | null;
      if ((m = p.match(/^"[^\s]?/))) { out.push('"'); p = p.slice(m[0].length); continue; }        // register prefix
      if ((m = p.match(/^[ia][wWsSpPbB(){}\[\]<>"'`ta]/))) { out.push(m[0]); p = p.slice(2); continue; } // text object
      if ((m = p.match(/^(dd|yy|cc|gg|ge|gE|gc|gu|gU|g~|gv|gn|gN|gJ|gq|gw|gi|gd|gf|gt|gT|gs|gr|ga|g8|g;|zz|zt|zb|zo|zc|za|zM|zR|zf|zj|zk|cs|ds|ys|cx|cr|ZZ|<<|>>|==|\[[a-z]|\][a-z])/))) { out.push(m[0]); p = p.slice(m[0].length); continue; }
      if ((m = p.match(/^[ftFTr]./))) { out.push(m[0][0]); p = p.slice(2); continue; }             // f{char}: the char is an argument
      if ((m = p.match(/^[0-9]+/))) { p = p.slice(m[0].length); continue; }                        // inner count (d3w)
      out.push(p[0]); p = p.slice(1);
    }
  }
  return out;
}

const cache = new Map<string, Set<string>>();

export function taughtBy(lessonId: string): Set<string> {
  const hit = cache.get(lessonId);
  if (hit) return hit;
  const lesson = LESSONS[lessonId];
  const set = new Set<string>();
  const add = (id: string) => { const l = LESSONS[id]; for (const c of [...l.chips, ...l.keyCards.map(k => k.key)]) for (const t of tokenize(c)) set.add(t); };
  if (lesson?.challenge.kind === 'generated') {
    for (const sid of lesson.challenge.sections) for (const l of SECTIONS.find(s => s.id === sid)?.lessons ?? []) add(l.id);
    set.add('COUNT');
  } else {
    let past = false;
    for (const l of ORDER) {
      if (l.challenge.kind === 'generated') continue;
      add(l.id);
      if (l.id === COUNTS_TAUGHT_FROM) past = true;
      if (past) set.add('COUNT');
      if (l.id === lessonId) break;
    }
  }
  cache.set(lessonId, set);
  return set;
}

export function usesAllowed(uses: string[], taught: Set<string>): boolean {
  return uses.every(u => taught.has(u));
}

export function coachable(lessonId: string): boolean {
  const l = LESSONS[lessonId];
  if (!l) return false;
  if (l.challenge.kind !== 'rounds' && l.challenge.kind !== 'generated') return false;
  const sec = sectionOf(lessonId);
  if (sec.id === 'macros' || sec.band === 'plugins') return false;
  return true;
}
```

```ts
// src/coach/motion.ts
// Shorter ways to move from A to B, with the heuristics that make them good advice.
import { step } from '../lessons/runtime';
import type { Pos } from '../vim/types';

export type Cand = { keys: string; cost: number; uses: string[]; family: 'count' | 'word' | 'find' | 'line' | 'search' | 'basic' };

type State = { pos: Pos; want: number; find: { ch: string; forward: boolean; till: boolean } | null };
type Node = { st: State; keys: string; cost: number; uses: Set<string>; family: Cand['family'] };

const key = (s: State) => `${s.pos.line}:${s.pos.col}:${s.want === Infinity ? 'inf' : s.want}:${s.find ? s.find.ch + (s.find.forward ? '>' : '<') + (s.find.till ? 't' : 'f') : ''}`;
const isBlank = (l: string) => l.trim() === '';
const WORD = /[A-Za-z0-9_]/;

/** One motion on plain lines. Returns null when the motion fails (Vim would error). */
function move(lines: readonly string[], st: State, m: string, count: number): State | null {
  const { pos, want } = st;
  const last = (r: number) => Math.max(0, lines[r].length - 1);
  let p = pos, w = want, find = st.find;
  for (let n = 0; n < count; n++) {
    switch (m) {
      case 'h': case 'l': case 'w': case 'b': case 'e': case 'W': case 'B': case 'E': p = step(lines, m, p); w = p.col; break;
      case 'j': if (p.line + 1 >= lines.length) return null; p = { line: p.line + 1, col: Math.min(w === Infinity ? Infinity : w, last(p.line + 1)) }; break;
      case 'k': if (p.line === 0) return null; p = { line: p.line - 1, col: Math.min(w === Infinity ? Infinity : w, last(p.line - 1)) }; break;
      case '0': p = { line: p.line, col: 0 }; w = 0; break;
      case '^': { const c = Math.max(0, lines[p.line].search(/\S/)); p = { line: p.line, col: c === -1 ? 0 : c }; w = p.col; break; }
      case '$': p = { line: p.line, col: last(p.line) }; w = Infinity; break;
      case 'G': p = { line: lines.length - 1, col: Math.max(0, lines[lines.length - 1].search(/\S/)) }; w = p.col; break;
      case 'gg': p = { line: 0, col: Math.max(0, lines[0].search(/\S/)) }; w = p.col; break;
      case '}': { let r = p.line + 1; while (r < lines.length && !isBlank(lines[r])) r++; if (r >= lines.length) r = lines.length - 1; p = { line: r, col: r === lines.length - 1 && !isBlank(lines[r]) ? last(r) : 0 }; w = p.col; break; }
      case '{': { let r = p.line - 1; while (r >= 0 && !isBlank(lines[r])) r--; if (r < 0) r = 0; p = { line: r, col: 0 }; w = 0; break; }
      case 'ge': case 'gE': { const l = lines[p.line]; let c = p.col - 1; const cls = (ch: string) => (m === 'gE' ? /\S/.test(ch) : WORD.test(ch)); while (c > 0 && !cls(l[c])) c--; while (c > 0 && cls(l[c - 1]) === cls(l[c]) && (m === 'gE' || WORD.test(l[c]) === WORD.test(l[c - 1]))) c--; if (c <= 0 && p.col === 0) return null; p = { line: p.line, col: Math.max(0, c) }; w = p.col; break; }
      default: {
        // f t F T ; ,
        let ch: string, forward: boolean, till: boolean;
        if (m === ';' || m === ',') { if (!find) return null; ch = find.ch; till = find.till; forward = m === ';' ? find.forward : !find.forward; }
        else { ch = m[1]; forward = m[0] === 'f' || m[0] === 't'; till = m[0] === 't' || m[0] === 'T'; find = { ch, forward, till }; }
        const l = lines[p.line];
        let c = p.col;
        if (forward) { c = l.indexOf(ch, p.col + 1 + (till && m.length === 1 ? 1 : 0)); if (c < 0) return null; if (till) c--; }
        else { c = l.lastIndexOf(ch, p.col - 1 - (till && m.length === 1 ? 1 : 0)); if (c < 0) return null; if (till) c++; }
        p = { line: p.line, col: c }; w = c;
      }
    }
  }
  return { pos: p, want: w, find };
}

const SINGLES = ['h', 'j', 'k', 'l', 'w', 'b', 'e', 'W', 'B', 'E', '0', '^', '$', 'ge', 'gE'];
const tok = (m: string) => (m.length === 2 && /^[ftFT]/.test(m) ? m[0] : m);

export function betterMotions(lines: readonly string[], from: Pos, want: number, to: Pos, maxCost: number, taught: Set<string>): Cand[] {
  const allow = (t: string) => taught.has(t);
  const counts = taught.has('COUNT');
  const start: Node = { st: { pos: from, want, find: null }, keys: '', cost: 0, uses: new Set(), family: 'basic' };
  const best = new Map<string, number>([[key(start.st), 0]]);
  const frontier: Node[] = [start];
  const found: Cand[] = [];
  const targetLast = to.line === lines.length - 1, targetFirst = to.line === 0, targetBlank = isBlank(lines[to.line]);

  const expand = (n: Node, m: string, count: number, family: Cand['family'], uses: string[]) => {
    if (!uses.every(allow)) return;
    const cost = n.cost + (count > 1 ? 1 : 0) + (m.length === 2 && /^[ftFT]/.test(m) ? 2 : m === 'gg' || m === 'ge' || m === 'gE' ? 2 : 1);
    if (cost >= maxCost) return;
    const st = move(lines, n.st, m, count);
    if (!st) return;
    const k = key(st);
    if ((best.get(k) ?? Infinity) <= cost) return;
    best.set(k, cost);
    const node: Node = { st, keys: n.keys + (count > 1 ? String(count) : '') + m, cost, uses: new Set([...n.uses, ...uses]), family: n.keys ? n.family : family };
    if (st.pos.line === to.line && st.pos.col === to.col) found.push({ keys: node.keys, cost, uses: [...node.uses], family: node.family });
    else frontier.push(node);
  };

  while (frontier.length) {
    frontier.sort((a, b) => a.cost - b.cost);
    const n = frontier.shift()!;
    if (n.cost >= maxCost - 1) continue;
    for (const m of SINGLES) {
      expand(n, m, 1, ['w', 'b', 'e', 'W', 'B', 'E', 'ge', 'gE'].includes(m) ? 'word' : ['0', '^', '$'].includes(m) ? 'line' : 'basic', [tok(m)]);
      if (counts) {
        const max = 'hjkl'.includes(m) ? 9 : ['w', 'b', 'e', 'W', 'B', 'E'].includes(m) ? 3 : 1;
        for (let c = 2; c <= max; c++) expand(n, m, c, 'count', [tok(m), 'COUNT']);
      }
    }
    if (targetLast) expand(n, 'G', 1, 'line', ['G']);
    if (targetFirst) expand(n, 'gg', 1, 'line', ['gg']);
    if (targetBlank) { expand(n, '}', 1, 'line', ['}']); expand(n, '{', 1, 'line', ['{']); }
    const l = lines[n.st.pos.line];
    const seen = new Set<string>();
    for (let c = 0; c < l.length; c++) {
      const ch = l[c];
      if (ch === ' ' || seen.has(ch)) continue;
      seen.add(ch);
      for (const f of ['f', 't', 'F', 'T']) expand(n, f + ch, 1, 'find', [f]);
    }
    if (n.st.find) { expand(n, ';', 1, 'find', [';']); expand(n, ',', 1, 'find', [',']); }
    // /prefix<CR>: shortest identifier prefix at `to` whose first match after `from` (wrapping) is `to`.
    const word = /[A-Za-z_][A-Za-z0-9_]*/.exec(lines[to.line].slice(to.col))?.[0];
    if (word && allow('/') && !n.keys) {
      for (let len = 1; len <= word.length; len++) {
        const pre = word.slice(0, len);
        const first = firstMatch(lines, from, pre);
        if (first && first.line === to.line && first.col === to.col) { const cost = 2 + len; if (cost < maxCost) found.push({ keys: `/${pre}<CR>`, cost, uses: ['/'], family: 'search' }); break; }
      }
    }
  }
  const rank = (c: Cand) => c.cost * 100 + new Set(c.keys.replace(/[0-9]/g, '')).size * 10 + (c.family === 'find' && lines[to.line].split(c.keys.slice(-1)).length > 2 ? 1 : 0);
  found.sort((a, b) => rank(a) - rank(b));
  const uniq = new Map<string, Cand>();
  for (const c of found) if (!uniq.has(c.keys)) uniq.set(c.keys, c);
  return [...uniq.values()];
}

function firstMatch(lines: readonly string[], from: Pos, pat: string): Pos | null {
  const n = lines.length;
  for (let d = 0; d <= n; d++) {
    const r = (from.line + d) % n;
    const startCol = d === 0 ? from.col + 1 : 0;
    const c = lines[r].indexOf(pat, startCol);
    if (c >= 0 && !(d === n && c > from.col)) return { line: r, col: c };
  }
  return null;
}
```

```ts
// src/coach/rules.ts
// Edit rules: windows of segments a better Vim user would have typed differently.
import type { Segment } from './segment';

export type Suggestion = { keys: string; saves: number; why: string; rule: string; uses: string[] };
export type RuleCtx = { lines: readonly string[] };
export type Rule = { id: string; uses: string[]; apply(segs: Segment[], i: number, ctx: RuleCtx): { consumed: number; suggestion: Suggestion } | null };

export const WHY: Record<string, string> = {
  'count-x': 'A count repeats a command: 3x deletes three characters.',
  'count-x-word': 'de deletes to the end of the word in one go.',
  'x-i-to-r': 'r replaces the character under the cursor without entering insert mode.',
  'A-at-eol': 'A appends at the end of the line from anywhere on it.',
  'I-at-bol': 'I inserts at the first non-blank character of the line.',
  'ddp': 'ddp swaps a line with the one below it.',
  'count-dd': 'A count before dd deletes several lines at once.',
  'dot-repeat': '. repeats the last change.',
  'cw': 'cw changes the word and drops you into insert mode.',
  'o-not-A-CR': 'o opens a new line below and enters insert mode.',
  motion: 'Fewer keys to the same spot.',
};

const keys = (s: Segment) => s.keys.join('');
const edit = (s: Segment | undefined) => (s && s.kind === 'edit' ? s : null);
const motion = (s: Segment | undefined) => (s && s.kind === 'motion' ? s : null);
const insertText = (k: string) => { const m = /^[iaAIoO](.*)<Esc>$/.exec(k); return m ? m[1] : null; };
const isWordEnd = (l: string, col: number, n: number) => {
  const span = l.slice(col, col + n);
  return /^[A-Za-z0-9_]+$/.test(span) && (col === 0 || !/[A-Za-z0-9_]/.test(l[col - 1])) && !/[A-Za-z0-9_]/.test(l[col + n] ?? ' ');
};
const mk = (rule: string, keys: string, learnerKeys: number, uses: string[], why = WHY[rule]): Suggestion => ({ keys, saves: learnerKeys - keys.replace(/<Esc>/g, 'E').replace(/<CR>/g, 'R').length, why, rule, uses });

export const RULES: Rule[] = [
  {
    id: 'count-x', uses: ['x', 'COUNT'],
    apply(segs, i, ctx) {
      let n = 0;
      while (edit(segs[i + n]) && keys(segs[i + n]) === 'x') n++;
      if (n < 3) return null;
      const s = segs[i] as Segment & { kind: 'edit' };
      const l = ctx.lines[s.from.line];
      if (s.from.col + n > l.length) return null;                 // x walked backwards at end of line
      if (isWordEnd(l, s.from.col, n)) return { consumed: n, suggestion: mk('count-x', 'de', n, ['d', 'e'], WHY['count-x-word']) };
      return { consumed: n, suggestion: mk('count-x', `${n}x`, n, ['x', 'COUNT']) };
    },
  },
  {
    id: 'x-i-to-r', uses: ['r'],
    apply(segs, i) {
      const a = edit(segs[i]), b = edit(segs[i + 1]);
      if (!a || !b || keys(a) !== 'x') return null;
      const t = insertText(keys(b));
      if (t === null || t.length !== 1 || !/^[ia]/.test(keys(b))) return null;
      if (b.from.line !== a.from.line || b.from.col !== a.from.col) return null;
      return { consumed: 2, suggestion: mk('x-i-to-r', `r${t}`, a.keys.length + b.keys.length, ['r']) };
    },
  },
  {
    id: 'A-at-eol', uses: ['A'],
    apply(segs, i, ctx) {
      const m = motion(segs[i]), e = edit(segs[i + 1]);
      if (!m || !e || !/^a/.test(keys(e))) return null;
      if (m.to.col !== Math.max(0, ctx.lines[m.to.line].length - 1)) return null;
      const t = insertText(keys(e)); if (t === null) return null;
      return { consumed: 2, suggestion: mk('A-at-eol', `A${t}<Esc>`, m.keys.length + e.keys.length, ['A']) };
    },
  },
  {
    id: 'I-at-bol', uses: ['I'],
    apply(segs, i) {
      const m = motion(segs[i]), e = edit(segs[i + 1]);
      if (!m || !e || keys(m) !== '^' || !/^i/.test(keys(e))) return null;
      const t = insertText(keys(e)); if (t === null) return null;
      return { consumed: 2, suggestion: mk('I-at-bol', `I${t}<Esc>`, m.keys.length + e.keys.length, ['I']) };
    },
  },
  {
    id: 'ddp', uses: ['dd', 'p'],
    apply(segs, i) {
      const a = edit(segs[i]), m = motion(segs[i + 1]), b = edit(segs[i + 2]);
      if (!a || !m || !b || keys(a) !== 'dd') return null;
      if (keys(m) === 'j' && keys(b) === 'P') return { consumed: 3, suggestion: mk('ddp', 'ddp', 4, ['dd', 'p']) };
      if (keys(m) === 'k' && keys(b) === 'P') return { consumed: 3, suggestion: mk('ddp', 'ddkP', 4, ['dd', 'k', 'P']) };
      return null;
    },
  },
  {
    id: 'count-dd', uses: ['dd', 'COUNT'],
    apply(segs, i) {
      let n = 0;
      while (edit(segs[i + n]) && keys(segs[i + n]) === 'dd') n++;
      if (n < 2) return null;
      return { consumed: n, suggestion: mk('count-dd', `${n}dd`, 2 * n, ['dd', 'COUNT']) };
    },
  },
  {
    id: 'cw', uses: ['c', 'w'],
    apply(segs, i) {
      const a = edit(segs[i]), b = edit(segs[i + 1]);
      if (!a || !b) return null;
      const t = insertText(keys(b));
      if (t === null || !/^i/.test(keys(b)) || b.from.line !== a.from.line || b.from.col !== a.from.col) return null;
      if (keys(a) === 'de') return { consumed: 2, suggestion: mk('cw', `cw${t}<Esc>`, a.keys.length + b.keys.length, ['c', 'w']) };
      if (keys(a) === 'dw' && t.endsWith(' ')) return { consumed: 2, suggestion: mk('cw', `cw${t.slice(0, -1)}<Esc>`, a.keys.length + b.keys.length, ['c', 'w']) };
      return null;
    },
  },
  {
    id: 'o-not-A-CR', uses: ['o'],
    apply(segs, i) {
      const e = edit(segs[i]); if (!e) return null;
      const m = /^A<CR>(.*)<Esc>$/.exec(keys(e)); if (!m) return null;
      return { consumed: 1, suggestion: mk('o-not-A-CR', `o${m[1]}<Esc>`, e.keys.length, ['o']) };
    },
  },
  {
    id: 'dot-repeat', uses: ['.'],
    apply(segs, i) {
      const a = edit(segs[i]); if (!a || a.command === 'visual') return null;
      let j = i + 1;
      while (motion(segs[j])) j++;
      const b = edit(segs[j]); if (!b || keys(b) !== keys(a)) return null;
      if (b.keys.length - 1 < 2) return null;                       // saves ≥ 2
      return { consumed: j - i + 1, suggestion: mk('dot-repeat', '.', b.keys.length, ['.']) };
    },
  },
];
```

```ts
// src/coach/index.ts
// "How would a better Vim user have done that?" over a session's key log.
import { LESSONS } from '../lessons';
import type { Challenge } from '../lessons/types';
import { solutionKeys } from '../lessons/runtime';
import { betterMotions } from './motion';
import { type SessionLike, sameOutcome, stateBefore, stateNeeds } from './replay';
import { RULES, type Suggestion, WHY } from './rules';
import { type Segment, segment } from './segment';
import { coachable, taughtBy, tokenize, usesAllowed } from './vocab';

export type { Suggestion };
export type Critique = { unit: number; you: string; better: Suggestion[]; logStart: number; logEnd: number };
export type RefLine = { unit: number; you: number; par: number; ref?: string };
export type Report = { critiques: Critique[]; reference: RefLine[] };
export type CoachSession = SessionLike & { challenge: Challenge; roundPar(unit: number): number | null; roundSolution(unit: number): string | null; carried(unit: number): boolean };

const MIN_SAVES = 2, RATIO = 1.5;
const worth = (learner: number, s: Suggestion) => s.saves >= MIN_SAVES || learner >= RATIO * (learner - s.saves);
const notation = (keys: string[]) => keys.join('');

/** Recording spans: segments between a `q<reg>` break and the next `q` break in the same unit. */
function recordingSpans(segs: Segment[]): Set<number> {
  const out = new Set<number>();
  let open = -1;
  segs.forEach((s, i) => {
    if (s.kind === 'break' && s.keys.length === 2 && s.keys[0] === 'q') open = i;
    else if (s.kind === 'break' && s.keys.length === 1 && s.keys[0] === 'q') open = -1;
    else if (open >= 0) out.add(i);
  });
  return out;
}

function verify(session: CoachSession, seg: Segment, endSeg: Segment, keys: string): boolean {
  const log = session.log();
  const a = stateBefore(session, seg.logStart);
  for (let k = seg.logStart; k <= endSeg.logEnd; k++) a.feed(log[k].key);
  const b = stateBefore(session, seg.logStart);
  b.feedKeys(keys);
  return sameOutcome(a, b, stateNeeds(log, endSeg.logEnd, seg.unit));
}

export function coachSegment(session: CoachSession, lessonId: string, seg: Segment, segs: Segment[], i: number): Critique | null {
  if (!coachable(lessonId)) return null;
  const taught = taughtBy(lessonId);
  const lesson = LESSONS[lessonId];
  const drilled = new Set(lesson.chips.flatMap(tokenize));
  const usedDrilled = (keys: string[]) => keys.some(k => drilled.has(k) || drilled.has(k[0]));
  if (recordingSpans(segs).has(i)) return null;

  if (seg.kind === 'motion') {
    if (usedDrilled(seg.keys)) return null;
    const vim = stateBefore(session, seg.logStart);
    const cands = betterMotions(vim.buf.lines, seg.from, vim.win.want, seg.to, seg.keys.length, taught);
    const better: Suggestion[] = [];
    for (const c of cands) {
      const s: Suggestion = { keys: c.keys, saves: seg.keys.length - c.cost, why: WHY.motion, rule: 'motion', uses: c.uses };
      if (!worth(seg.keys.length, s) || !usesAllowed(c.uses, taught)) continue;
      if (!verify(session, seg, seg, c.keys)) continue;
      better.push(s);
      if (better.length === 2) break;
    }
    return better.length ? { unit: seg.unit, you: notation(seg.keys), better, logStart: seg.logStart, logEnd: seg.logEnd } : null;
  }
  if (seg.kind === 'edit') {
    const lines = stateBefore(session, seg.logStart).buf.lines;
    for (const r of RULES) {
      const hit = r.apply(segs, i, { lines });
      if (!hit) continue;
      const span = segs.slice(i, i + hit.consumed);
      const learner = span.reduce((a, s) => a + s.keys.length, 0);
      if (span.some(s => usedDrilled(s.keys) && s.kind === 'edit')) continue;
      if (!worth(learner, hit.suggestion) || !usesAllowed(hit.suggestion.uses, taught)) continue;
      if (!verify(session, seg, span[span.length - 1], hit.suggestion.keys)) continue;
      return { unit: seg.unit, you: span.map(s => notation(s.keys)).join(''), better: [hit.suggestion], logStart: seg.logStart, logEnd: span[span.length - 1].logEnd };
    }
  }
  return null;
}

export function coach(session: CoachSession, lessonId: string): Report {
  const empty: Report = { critiques: [], reference: [] };
  if (!coachable(lessonId)) return empty;
  const segs = segment(session.log());
  const critiques: Critique[] = [];
  let i = 0;
  while (i < segs.length) {
    const c = coachSegment(session, lessonId, segs[i], segs, i);
    if (c) { critiques.push(c); i = segs.findIndex((s, k) => k > i && s.logStart > c.logEnd); if (i < 0) break; }
    else i++;
  }
  // Merge a motion critique with a rule critique that consumed the same motion (jj$a → 2j + A).
  for (let k = critiques.length - 1; k > 0; k--) {
    const a = critiques[k - 1], b = critiques[k];
    if (a.logEnd >= b.logStart) { a.better = [...a.better, ...b.better]; a.logEnd = b.logEnd; a.you = a.you; critiques.splice(k, 1); }
  }
  critiques.sort((a, b) => Math.max(...b.better.map(s => s.saves)) - Math.max(...a.better.map(s => s.saves)) || a.unit - b.unit || a.logStart - b.logStart);

  const reference: RefLine[] = [];
  const taught = taughtBy(lessonId);
  if (session.challenge.kind === 'rounds') {
    const log = session.log();
    for (let u = 0; u < session.challenge.rounds.length; u++) {
      const par = session.roundPar(u);
      const sol = session.roundSolution(u);
      if (par === null || sol === null) continue;
      const you = log.filter(e => e.unit === u).length;
      if (you - par < MIN_SAVES) continue;
      const refKeys = solutionKeys(sol);
      const ok = usesAllowed(refKeys.flatMap(k => tokenize(k)), taught);
      reference.push({ unit: u, you, par, ref: ok && !session.carried(u) ? sol : undefined });
    }
  }
  reference.sort((a, b) => (b.you - b.par) - (a.you - a.par));
  return { critiques, reference: reference.slice(0, 3) };
}
```
