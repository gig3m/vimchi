# P2 design: reps, review, and a coach that teaches (2026-09-30)

Status: owner-approved scope (SYNTHESIS.md items 13–18); interfaces decided here so parallel
workers agree. Evidence: `docs/superpowers/audit/2026-09-30-sweep/{claude-fidelity,codex-fidelity,claude-coach}.report.md`.

## 1. Reps (item 13) — the volume lever

A lesson's authored rounds stay the worked introduction. After them, **Reps** offers 10–15
generated mini-rounds of that lesson's edit on corpus files, with random sites and positions.

- `Lesson.reps?: RepsSpec` where
  `RepsSpec = { mutations: string[]; count: [number, number]; corpus?: 'code' | 'prose'; sections: string[] }`.
  `mutations` are ids of `MutationKind`s in `src/challenges/mutations/`; new skill-keyed kinds
  live in `src/challenges/mutations/reps.ts` (e.g. `wrong-string-contents` → `ci"`/`ci'`,
  `stray-arg` → `daa`, `wrong-args` → `ci(`, `extra-block` → `dap`/`daf`, `indent-off` → `>ip`/`=ip`,
  `stray-line`×3 → `dd` then `.`, `wrong-word`×3 → `cw` then `.` or `cgn`).
- `src/challenges/reps.ts` exports `repsChallenge(lesson: Lesson, seed?: number): GeneratedChallenge`
  building a `generated` challenge from the spec (reuse `generate.ts`; a lesson's reps use the
  corpus subset matching `corpus`). Replacement text drawn from the corpus is ≤ 6 characters.
- Routing: `#<lesson-id>?reps=<seed>` opens the lesson in Reps mode (`src/state/seed.ts` gains
  `repsFromHash` / `repsHref`). The lesson page shows the authored practice as today; a **Reps**
  button on the results screen and under the practice editor switches to reps mode; the
  "Better ways" report and checklist work as they do for challenges.
- Runs from reps are stored with lesson id `<lesson-id>-reps` (fits the server rule
  `^[a-z0-9-]{1,64}$`). `COUNTED`/completion ignore them; Profile shows them as "<Title> reps".
- First wave: reps for these lesson families (specs on each lesson): intro-operators,
  delete-words, change-words, delete-lines, text-objects-quotes, text-objects-parens,
  word-objects, argument-objects, indent-objects, function-class-objects, repeat-last-change,
  counts-operators, search-forward/word-under-cursor (`cgn` family). Others later.

## 2. Spaced mixed review "Warm-up" (item 14)

An 8–10 item set drawn from the Reps generators of lessons finished ~1, 3, 7 and 21 days ago,
weighted toward low `acc`/`speed` in the learner's runs. No schema change. Routing `#warm-up`;
sidebar entry above the bands. Depends on §1; second wave.

## 3. Coach: idiom search (item 15)

Replace the nine hand rules in `src/coach/rules.ts` with one edit-equivalence search in
`src/coach/idiom.ts`: for each edit window (edits with only motions between, bounded by a break),
compute the net change (buffer diff + final cursor/mode) and search the taught grammar
`[count] operator (motion | text-object)`, `[count] x/X/~`, `r/s/S/C/D/cc/J/>>/<<`, then
`insert-text <Esc>`, plus `.`/`n.`/`;` repeats. Score by **style cost**, not raw keys: text object
< f/t motion < word motion < count; `Nx` with N > 3 penalised; mixed vertical/horizontal
penalised. Replay-verify with the existing `sameOutcome`/`stateNeeds`. Prefer a route using the
current lesson's chips. The nine rules become regression tests in `rules.test.ts` (they must
still be found). Every suggestion carries a `pattern` id (§4).

## 4. Coach: why, links, summary (item 16)

`src/coach/patterns.ts`: `PATTERNS: Record<id, { name; principle; lesson: string }>` — e.g.
`find-char` ("jump to a character you can see", lesson `find-char`), `op-to-char`, `text-object`,
`dot`, `count-op`, `line-end-insert`, `jump-line`, `search-jump`. Suggestion gains
`pattern: string`; the results panel shows `name — principle` and a "Review: <Lesson> →" link
(`#<lesson-id>`). Live hint text becomes `name: keys (N instead of M)`. Motion critic: canonical
routes (one vertical leg `Nj`/`NG`/`gg`/`{`/`}`/`/`/`<C-d>`, then one horizontal leg
`0 ^ $ f t w b e ;`), `NG`/`%`/`H/M/L`/`<C-d>`/`n` as first-class moves once taught, `/search`
ranked below `f`/`t` for same-line targets, ONE suggestion per critique. Report header:
"You used N keys: A moving, B typing, C editing. Par P." Generated challenges get per-item
"Edit k: par a, you b" lines, worst three first.

## 5. Coach memory (item 17) — second wave

`CoachEvent` per critique appended to a run (`pattern, unit, you, better, used, at`) and a
`CoachProfile` per user (pattern counts, fixed streaks, key mix rolling 20 runs), server-side
table + local mirror for guests. Enables "4th run in a row: x-runs to end of line → D", mastery
retirement of hints, review selection input for §2, and a Coach page in Profile. Patterns and
counts only; no keys or text leave the browser.
